Frequently asked questions

What data do you need to start?

Whatever exports you already have — CSV from your booking system, POS, accounting package or CRM. The cleaning pipeline handles the mess; you don't need to tidy it first.

Is my data safe?

We scope data handling explicitly per engagement and use the minimum necessary. In our demonstration product, CSV import runs entirely in your browser and the file never leaves your machine.

Do I need a data team to use it?

No. That's the point. The dashboard is built to be read by an owner or manager, and the copilot answers plain-language questions without anyone writing a query.

Can it connect to live systems?

Yes, where an API exists. We often start with exports to prove the value quickly, then wire up live connections once the dashboard is earning its place.
